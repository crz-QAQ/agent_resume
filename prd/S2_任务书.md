## 一、本块范围（只做这 2 件）

### 1. 新建 `app/resume_parser.py`

```python
@dataclass
class ResumeParseResult:
    status: str          # ok / needs_review / failed
    data: ResumeInfo | None
    reasons: list[str]
    raw_text: str        # 原文，S6 取 evidence 必须用
    cost_yuan: float
    file_name: str

async def parse_resume_file(filename: str, raw: bytes) -> ResumeParseResult:
    """文件字节 → 文本 → 结构化；保留原文供后续取证据。"""
```

**实现要求**：

1. **复用，不重写**
   - 解析：`from app.file_parser import extract_text, FileParseError, UnsupportedFormatError, ScannedPdfError`
   - 抽取：`from app.agent import parse_resume_agent`
2. **大小限制**：模块级常量 `MAX_UPLOAD_BYTES = 10 * 1024 * 1024`（10MB），超限抛 `FileParseError("文件超过 10MB 上限")`；注释写明出处（与现有 `/resume/upload` 的 10MB 一致）
3. **空文本判定**：`extract_text` 返回空白字符串时抛 `FileParseError("文件没有可解析的文本")`
4. **状态映射**（与现有接口保持一致，不许自创）
   ```
   AgentResult.status 原样传递：ok / needs_review / failed
   解析异常（FileParseError 及其子类）→ 直接向上抛，不吞掉
   ```
5. **raw_text 必须原样保留**（不许 strip 后只留摘要），注释写明「S6 的 evidence 从这里截取」

### 2. 新建 `tools/check_resume_parser.py`

验证脚本，用现成的 4 份测试文件（`tools/test_files/`）：

| 文件 | 期望 |
|---|---|
| `clean_resume.docx` | status=ok，name/years/skills 抽到 |
| `table_resume.docx` | status=needs_review 或 ok，**必须抽到表格里的经历** |
| `text_resume.pdf`（双栏）| 抽到文本，首行不是「李娜 工作经历」串行（S0 之前修过的双栏问题）|
| `scan_resume.pdf`（扫描件）| 抛 `ScannedPdfError` → 判为「明确拒绝」PASS |

脚本要打印：每份文件的 status / name / years / skills / 文本长度 / 成本，末行输出「通过 X/4」与总成本。
